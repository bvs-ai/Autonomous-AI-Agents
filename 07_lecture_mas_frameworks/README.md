# Лекція 7 — мультиагентні фреймворки. Демо-код для студентів

Тринадцять запусканих скриптів: **одна й та сама задача, розв'язана трьома
фреймворками** — CrewAI, Microsoft Agent Framework і Google ADK.

Задача одна навмисно. Змінна, яку ми досліджуємо, — фреймворк, і тільки він.
Домен спільний: підтримка платіжного сервісу, тікет про подвійне списання
49.99 USD.

**Ці демо ходять у справжню модель** (Gemini), тому потрібен ключ, а вивід
щоразу трохи інший.

Основна лінія — драбина з трьох кроків, повторена тричі:

| Крок | Питання кроку | CrewAI | Agent Framework | ADK |
|---|---|---|---|---|
| 1 | як описується агент та інструмент | `c1` | `m1` | `g1` |
| 2 | **як саме течуть дані між агентами** | `c2` | `m2` | `g2` |
| 3 | хто обирає маршрут і скільки це коштує | `c3` | `m3` | `g3` |

Решта файлів (`c3b`, `c4`, `c5`, `m3b`, `g3b`, `trace_llm.py`) — **бонусні**:
вони поглиблюють крок 3 або показують інші способи написати те саме. Без них
основна думка лекції не постраждає, беріться за них за бажанням.

## Встановлення

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp .env.example .env          # вписати свій GOOGLE_API_KEY
.venv/bin/python common.py    # перевірка, що ключ живий
```

Ключ безкоштовний: https://aistudio.google.com/apikey. Одного `GOOGLE_API_KEY`
вистачає на всі три фреймворки.

> **Про ліміти.** Безкоштовний тариф Gemini дає 15 запитів за хвилину, а крок 3
> у CrewAI витрачає до 9 викликів за один прогін. Запускайте скрипти по одному.
> Якщо впіймали `429` — зачекайте хвилину, це не поламаний код.

Подробиці про встановлення, ліміти й формат виводу — у
[`student_docs/README.md`](student_docs/README.md).
